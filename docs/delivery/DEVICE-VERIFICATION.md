# 真机验证清单（待真机验证）

v0.1.0 在本机用 JVM/Robolectric、Playwright（Chrome + 模拟 HID/相机）和原生 `--foreground` 冒烟完成软件验证。下列条目在开发计划 M6 发布门禁中标记为 **待真机验证**，需 1 台中端 Android 平板（建议 4–6GB，骁龙 6 Gen 1 / 天玑 7050 级或同类）+ 1 把支持 HID 与 SPP 的经典蓝牙扫描枪 + 一台现场标签打印机。未完成前不得把「现场已验收」写入上线签字。

建议在安装 `wms3d-v0.1.0.apk`、指向现场或预发 API、使用非演示口令的测试仓后执行。每条记录：通过 / 失败 / 跳过、机型、系统版本、WebView 版本、枪型号、打印机型号、拍摄或日志路径。

## A. 蓝牙 HID 扫码枪

- [ ] 平板配对成功，系统识别为键盘/HID。
- [ ] 作业页（上架）在**中文输入法且焦点在输入框**时，连续扫 50 次仓位/SKU，**零吞字、零丢码**。
- [ ] 终止符（回车）可配置，与枪出厂设置一致。
- [ ] 非白名单键盘按键不被插件误吞。
- [ ] 若 HID 失败：可切换 SPP，或使用作业页「无焦点」兜底，并记录现象。

## B. 蓝牙 SPP

- [ ] 经典蓝牙配对、在应用内选择该设备后可收码。
- [ ] 休眠或熄屏超过 5 分钟后唤醒，**第一枪**即可出码（无丢首包）。
- [ ] 半帧/粘包情况下应用能拼出完整条码（对照枪端设置）。
- [ ] 与 HID 模式切换后无需重装应用。

## C. 手机/平板相机扫码

- [ ] 打开相机模式，上半屏预览不被 UI 遮挡，瞄准框可见。
- [ ] 标准仓位标签（100×50 等）在正常仓内光照下 1 秒内识出。
- [ ] 密集排列的多枚标签，误读率可接受（记录误读次数与距离）。
- [ ] 连续扫 20 个不同仓位，无重复提交、无漏记。
- [ ] 手电筒（若设备支持）可开关。

## D. 离线队列与补传

- [ ] 打开飞行模式，连续做 10 单上架/拣货，全部进入待传且界面有提示。
- [ ] 恢复网络后自动按序补传，服务端库存与台账正确，**无重复记账**。
- [ ] 令牌在离线期间过期，恢复后可刷新并继续上传，不被踢到登录页丢单。
- [ ] 换班：A 离线单据在 A 登出、B 登录后由 B 提交成功，`performedBy` 仍为 A；伪造执行人被拒。
- [ ] 待传队列导出/异常单可打开。

## E. 实机标签打印

- [ ] 管理后台预览 PDF 后，在 Windows/Linux 用系统阅读器 **100% 缩放** 打印到现场热敏或激光机。
- [ ] 实物尺寸与模板一致（用校准页量长宽，误差在允差内）。
- [ ] 打印出的仓位/货架/SKU 条码可被本枪或本机相机回读；后台「回读核对」对扫描件通过。
- [ ] 补打队列可标记完成。
- [ ] ZPL 直出（若启用实验项）在斑马类打印机上的效果另记，失败不阻断 PDF 路径。

## F. 3D 帧率与定位（中端平板）

- [ ] 演示仓（约四百仓位）首屏 ≤ 3 秒，操作流畅。
- [ ] 若有 5,000 仓位测试布局：≥ 30 FPS，首屏 ≤ 3 秒。
- [ ] 若有 20,000 仓位：远景 LOD 后 ≥ 24 FPS，首屏 ≤ 5 秒。
- [ ] SKU 定位：缓存命中时，从点「定位」到相机开始飞行 ≤ 1 秒；高亮醒目，其余仓位明显压暗。
- [ ] WebGL2 不可用或强制 2D 时，平面图可操作并有提示。

## G. 设备兼容与安全

- [ ] 目标现场机型（含华为/无 GMS）能安装 APK、启动、通过 WebView 版本门槛。
- [ ] `allowBackup=false` 下，卸载重装后安全存储中的令牌不随系统备份恢复。
- [ ] 用户锚点证书路径：内部 CA 安装后能连 HTTPS API；证书错误时拒绝连接。
- [ ] 30 分钟现场走查：登录 → 扫码上架 → 3D 可见 → 定位 → 出库 → 看台账，无阻断缺陷。
