# 用户手册

适用版本 v0.1.0。演示账号与启动方式见 `README.md`。

## 一、系统管理员（admin，PC）

### 1. 登录与改密
打开管理后台地址，输入用户名和密码。生产环境首次登录若提示改密，请设置符合策略的新密码。右上角可退出。

### 2. 用户与仓库授权
「系统 → 用户与设备」：新建用户、指定角色（管理员/主管/仓管员/只读）、勾选可访问仓库或「全部仓库」、重置密码、停用设备（使该设备刷新令牌立刻失效）。

### 3. 建仓与布局
1. 「仓库设计 → 仓库 / 库区 / 货架」确认仓库尺寸、时区、编码规则。
2. 「货架模板」维护列数、层数、位深、默认容量。
3. 「布局设计器」：从当前发布版或空白创建草稿；在 2D 平面拖拽货架、旋转、阵列复制；可用「适配视图」看全仓；打开「3D 预览」对照同一范围。
4. 「校验并发布」：处理错误/改码确认，发布后生成仓位投影。旧码若变更，按提示处理待补打。

### 4. SKU 与标签
- 「主数据 → SKU」：新增或 CSV 导入（先预检错误报告）。设置条码、包装倍数、安全库存。
- 「标签打印」：选择仓位/货架/SKU → 选模板（如 loc-100x50）→ 预览 PDF → 下载后用系统阅读器按 100% 打印。可用「回读核对」检查条码是否可读。补打在「补打队列」。打印前建议先打校准页，避免驱动缩放。

### 5. 库存、盘点、预警与审计
- 「库存查询 / 流水台账 / 交易单」：按仓位或 SKU 查询；主管可冲正。
- 「盘点」：新建（选库区、是否盲盘）→ 开始 → 移动端执行 → 「提交审核」→ 查看差异 → 关闭（生成盘点调整）。有待同步单据时需确认。
- 「低库存预警」与「看板」：安全库存缺口、今日出入库、利用率、待同步、备份状态。
- 「审计日志」：登录、主数据、发布、调整、盘点关闭等留痕，不可改。
- 「3D 孪生」：占用图例；搜索 SKU 定位，高亮仓位并框住所在货架。

### 6. 备份意识
看板若提示未配置异地备份，请运维配置 `BACKUP_REMOTE` 并跑 `pnpm backup:drill`。不要只把备份放在与数据库同一块盘。

## 二、仓库主管（manager）

与管理员相同的库存、标签、盘点、预警、布局草稿权限，但没有「用户与设备」。布局发布通常仍需管理员。日常：导入 SKU、打印标签、审核盘点差异、关注低库存与看板。

## 三、仓管员（op，平板或手机）

### 1. 设备准备
- 平板建议用支架 + 蓝牙枪。在「更多 → 扫码测试 / 扫码枪设置」完成配对。
- HID 模式：系统把枪识别为键盘；作业页会拦截按键。若中文输入法吞字，改用 SPP 或保持光标不在输入框。
- SPP 模式：在设置里选择已绑定的经典蓝牙设备。
- 仅手机、无枪：用「相机扫码」，把标签置于瞄准框内。

### 2. 上架（入库）
打开「作业」→ 选择「上架」。扫仓位（或 `WH1.仓位码`）→ 扫 SKU/条码 → 默认数量 1，可用数量键盘修改。连续模式在空闲数秒后自动提交，无需额外点击。最近记录可在时限内撤销。

### 3. 拣货（出库）
切换「拣货」，同样先仓位后 SKU。库存不足会拒绝并提示。不要在未完成上一笔时乱扫其他仓位（意外码会打断并提示）。

### 4. 移库
按页面提示扫源仓位、SKU、数量、目标仓位后提交。

### 5. 查询与 3D
「查询」输入 SKU 或条码，可「在 3D 中查看」。孪生页可点选仓位；「标签核对」连续扫仓位标签，已扫点亮，列表给出漏贴/错贴。

### 6. 盘点（盲盘）
「更多 → 盘点」选择进行中的任务。先扫仓位，再扫该位实有 SKU（界面不显示系统库存）。改数量后点「本仓位完成」。未扫到的 SKU 按 0 计。若提示本仓位有待传单据，先到「更多」同步。

### 7. 离线与换班
断网时可继续扫码，单据进待传队列，恢复网络后自动补传（幂等，不会重复记账）。换班：后一位登录可以代交上一班已离线的单据，执行人仍记为原操作员。异常单在「更多 → 异常单」处理。待传队列可导出备份。

### 8. 证书与换服务器
若现场使用内部 CA，按运维提供的用户锚点安装证书。更换服务器前清空本地数据，避免连错环境。
