# 00 · 总览（Overview）

> 设计版本：v1（2026-11-11）· 状态：待独立评审

## 1. 背景与目标

为中小型仓库（单仓 ≤ 2 万个仓位、≤ 5 万 SKU、≤ 50 台移动终端）提供一套**轻量、可落地**的 WMS，核心卖点是"所见即所存"的 3D 数字孪生：

1. **仓位数字化**：在 PC 后台可视化设计仓库 → 库区 → 货架 → 层 → 仓位，并批量打印仓位码/货架码。
2. **扫码作业极速化**：手机（摄像头）或平板 + 蓝牙扫码枪（HID 键盘模式 / SPP 串口模式），"扫仓位 → 扫商品 → 数量 → 确认"，常见路径 ≤ 3 次点击。
3. **库存透明化**：移动端 3D 孪生按真实库存给仓位着色；输入/扫描 SKU 立即在 3D 中高亮所在仓位并列出数量。
4. **可审计**：所有库存变动进入不可篡改的流水台账（ledger），余额可随时与台账对账。

### 成功标准（MVP 验收口径）
- 新仓库从 0 到可作业：设计 200 个仓位 + 打印标签 + 导入 500 SKU ≤ 1 小时。
- 平板 + 蓝牙枪单次上架（扫仓位、扫 SKU、默认数量 1、自动提交）≤ 3 秒，0 次额外点击（连续模式）。
- 中端 Android（如骁龙 6 Gen 1 / 天玑 7050 级，4–6GB RAM）上 5,000 仓位场景 ≥ 30 FPS，首屏 ≤ 3 秒。
- 网络抖动/断网时扫码不丢单：恢复联网后自动补传，**幂等**不重复记账。

## 2. 非目标（MVP 不做）
- 采购单/销售单/波次/拣货路径优化/越库/复杂 ASN（只保留"参考单号"字段，后续可接 ERP）。
- 批次 FEFO 策略、序列号、多计量单位换算（仅支持"包装条码 = N 个基本单位"）。
- 多租户 SaaS、计费、iOS 客户端、AGV/PLC 对接、RFID。
- BLE 扫码枪（仅经典蓝牙 SPP 与 HID）。
- 3D 中的人员/叉车实时定位。

## 5. 关键设计原则
1. **契约优先**：`packages/contracts`（Zod schema）是前后端唯一真相源，自动生成 OpenAPI 与类型。
2. **台账 + 余额**：不可变流水 + 物化余额同事务更新，数据库约束兜底（非负、幂等唯一键）。
3. **扫码即命令**：所有扫码动作都是带客户端幂等键的命令，可安全重放。
4. **一套 3D 代码**：three.js/R3F 场景包在 PC 与移动端（Capacitor WebView）复用。
5. **小而硬**：功能少，但每个功能有约束、测试和可观测性。

## 6. 术语
| 中文 | 英文/代码 | 说明 |
|---|---|---|
| 仓库 | Warehouse | 物理仓，坐标原点所在 |
| 库区 | Zone | 区域（常温区/冷库/收货区），编码 1 字母 |
| 巷道 | Aisle | 两排货架之间的通道编号 |
| 货架 | Rack | 一组立柱构成的货架单元（含多个列/Bay） |
| 列 | Bay | 货架沿巷道方向的一格 |
| 层 | Level | 自下而上 A、B、C… |
| 仓位/库位 | Location / Bin | 最小存储单元，有唯一编码与条码 |
| 流水 | Stock Movement | 不可变库存变动记录 |
| 余额 | Stock Balance | (仓位, SKU, 批次) 的当前在库数 |
