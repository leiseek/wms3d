# ADR-0006 · 标签：服务端矢量 PDF（pdfkit + bwip-js），ZPL 可选
- 状态：已接受 · **v2 2026-11-12**（按 R1 M20/M30/M31/M32 修订）

## 决策
- 默认输出 PDF（A4 多联 + 热敏尺寸页面，一页一张，方向固定）。pdfkit 不能导入 SVG，因此用 **bwip-js 自定义 drawing 接口**直接输出 pdfkit 矢量路径；X 维按 dpi 取整到点；渲染前按 `maxModules` 校验容量；提供校准页与驱动设置指引。
- ZPL 降级为**实验性**（M5 可选，仅 ASCII + 条码，`^CI28`），不做直发。
- 不做浏览器端 Canvas 打印（DPI/缩放不可控）；不做打印服务器（MVP）。

## 后果
+ 一致可复现、可单测（PDF→栅格→解码回读）；− 依赖用户以 100% 比例打印（UI 明确提示 + 校准偏移）。
