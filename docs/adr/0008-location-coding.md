# ADR-0008 · 仓位编码：由粗到细、定宽、可配置模式，路径顺序独立存储
- 状态：已接受（v1）

## 决策
- 默认 `{Zone}{Aisle:2}-{Bay:2}-{Level:A}{Pos:2}` → `A03-12-C02`；货架 `R-A03-01`；功能区 `RCV-01`/`SHP-01`/`QC-01`。
- 只用 `[A-Z0-9-]`；数字补零定宽；层字母自下而上；仓库内唯一，标签加印仓库代码。
- 每仓库可配置模式；产生仓位后锁定。拣货/盘点顺序用 `pick_seq`（步长 10）。
- 仓位码/货架码/SKU 条码同一命名空间去重，保证扫码分类无歧义。

## 依据
行业命名规范（sources [W1][W2][W3]）：由粗到细使字典序≈行走顺序、补零防排序错乱、避免 `/ . _ 空格`、层自下而上、编号预留增长空间。
