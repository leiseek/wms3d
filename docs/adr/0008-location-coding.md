# ADR-0008 · 仓位编码：巷道级连续 bay + 奇偶分侧；条码载荷带仓库前缀（v2）
- 状态：已接受 · **v2 2026-11-12**（按 R1 D14/M1、D18/M19、D21/D22、M18 修订）· **v2.1 2026-11-12**（按 R2 B-N1/M-N1 修正行进方向与右侧 bay 方向，M-N12 修订分类器）

## 背景
v1 模式 `{Zone}{Aisle:2}-{Bay:2}-{Level}{Pos:2}` 中 bay 在货架内编号，同巷道多个货架必然重码（两位评审均列为 BLOCKER）。

## 选项
- (a) **巷道级连续 bay 编号**，左奇右偶（选）：编码短、符合行业惯例、按编码排序即行走顺序；代价是货架需 `side/bayStart`，设计器需自动递增与区间校验。
- (b) 编码加 `{Rack:2}` 段（如 `A03-01-02-C02`）：实现简单，但编码变长（标签与 Code128 更宽）、现场读码时多一段认知负担。

## 决策
- 仓位码 `{Zone}{Aisle:2}-{Bay:2}-{Level:A}{Pos:2}` → `A03-17-C02`；Bay 可配置为 3 位。
- **巷道行进方向**（v2.1）：水平巷道 +X，竖直巷道 +Z。`side` 由货架旋转推导（0/90 → L，180/270 → R），不人工填写。
- bay 沿行进方向递增，左奇右偶，`bayStart` = 货架靠行进起点一端的号；i = 面对取货面从左到右的列序号：L 侧 `bayStart + 2i`，R 侧 `bayStart + 2·(bays−1−i)`。v2 的"两侧都面对取货面从左到右"会让 R 侧编号逆行进方向（R2 BLOCKER），已废止。
- position 面对取货面从左到右，level 自下而上（A 起）；坐标/旋转约定见 02 §2；校验同巷道两侧取货面共线、巷道宽度 ≥ 1.2m（警告）。
- 货架码 `R{Zone}{Aisle:2}-{Side}{RackNo:2}` → `RA03-L02`；功能区 `RCV-01`/`SHP-01`/`QC-01`。
- 字符集 `[A-Z0-9-]`，定宽补零，`COLLATE "C"`；仓库内唯一；已有仓位后模式不可改（由 EXISTS 推导）。
- **条码载荷** `{WarehouseCode}.{code}`（如 `WH1.A03-17-C02`，仓库开关默认开）；分类器先整串精确匹配登记表（SKU 条码可能含 `.`），再大写匹配，最后才解析前缀：已知仓库且不符 → `WRONG_WAREHOUSE`；无前缀按当前仓库解析（兼容手输）（v2.1 M-N12）。
- 组织级 `barcode_registry` 实体表（主键裁决冲突）+ advisory lock（双 int 形式，常量在 `apps/api/src/db/locks.ts`）串行化 SKU 条码写入与布局发布；停用仓位的载荷从登记表释放。
- `pick_seq` 独立存储。
