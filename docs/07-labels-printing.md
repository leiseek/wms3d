# 07 · 标签与打印

## 1. 方案（ADR-0006）
- **服务端渲染 PDF**（pdfkit + bwip-js 生成**矢量** SVG 条码嵌入，不栅格化），浏览器打开 PDF → 系统打印对话框（"实际大小 / 100%"）。适配任意打印机（A4 激光、热敏标签机的 Windows 驱动）。
- **ZPL 输出（可选，M5）**：同一模板描述生成 ZPL 文本（203/300 dpi），供斑马/兼容机直连（下载 .zpl 或经局域网 9100 端口发送——后者 MVP 不做）。
- 模板以 TypeScript 数据描述（`packages/labels`），纯函数 `renderPdf(template, items) / renderZpl(template, items, dpi)`，可单测（快照 + 条码解码回读验证）。

## 2. 内置模板
| 模板 key | 尺寸 | 用途 | 内容 |
|---|---|---|---|
| `loc-100x50` | 100×50mm 热敏 | 仓位 | 大号编码（≥ 10mm 高粗体）+ Code128 + 小 QR（可选）+ 仓库代码 + 层方向箭头 |
| `loc-60x40` | 60×40mm 热敏 | 仓位（层板架） | 编码 + Code128 |
| `loc-70x30` | 70×30mm 热敏 | 横梁窄标 | 编码 + Code128（单行） |
| `rack-100x150` | 100×150mm | 货架端头大标 | 货架码超大字 + QR + 巷道/列范围 |
| `a4-3x8` | A4，3 列×8 行（70×37mm，常见不干胶标签纸） | 仓位/SKU 批量 | 编码 + Code128 |
| `a4-2x7` | A4，2×7（99×38mm） | 仓位 | 编码 + Code128 + QR |
| `sku-60x40` | 60×40mm | SKU | 名称（截断两行）+ SKU 码 + 条码（EAN-13 合法则用 EAN，否则 Code128） |
A4 模板支持"起始位置"（跳过已用格子）与可调页边距/偏移（打印机校准，存于用户偏好）。

## 3. 条码规范
- 仓位/货架：**Code128**（字母数字高密度，所有扫码枪/ML Kit 均支持）；QR 仅作辅助（手机远距扫描），内容与 Code128 相同的**纯编码**（不带 URL，避免误开浏览器）。
- 模块宽度：热敏 203dpi 下 X 维 ≥ 0.25mm（2 dots），300dpi 下 0.254mm（3 dots）；条高 ≥ 10mm；左右静区 ≥ 10X；
- 按打印机分辨率对齐点阵：模板参数 `dpi` 决定 X 维取整，避免条宽不均导致识读失败。
- 人眼可读文本与条码内容一致；字体内嵌 Noto Sans SC（子集化，支持中文仓库名/SKU 名）。
- 冷库/高位：高位仓位用 `rack-100x150` 或大号 QR（≥ 50mm，长距离扫描）。

## 4. 打印流程（PC）
选对象（按库区/货架/仓位多选/筛选；SKU 列表多选）→ 选模板 → 预览（内嵌 PDF iframe，前 1 页实时）→ "下载 PDF / 打印"。批量上限 5,000 张/次（流式生成，约 < 10s）。记录审计（谁、打了什么、数量）。

## 5. 张贴规范（写入用户手册）
同一高度/同一侧张贴；层标签贴在该层横梁正中下方；底层仓位标签朝上倾斜或贴在上方横梁避免弯腰；张贴后用平板"标签核对"模式逐个扫描校验（扫到即在 3D 中点亮，漏贴一目了然）——这是一个低成本高价值的 MVP 功能。
