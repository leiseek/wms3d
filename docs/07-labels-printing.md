# 07 · 标签与打印

> v2（2026-11-12）：条码矢量绘制改用 bwip-js 自定义 drawing → pdfkit；载荷带仓库前缀；X 维与容量校验；打印驱动指引与校准页；ZPL 降为实验性；补打请求队列。

## 1. 方案（ADR-0006 v2）
- **服务端 PDF**：pdfkit 0.20 + bwip-js 4.11。pdfkit **不能导入 SVG**，因此使用 bwip-js 的**自定义 drawing 接口**（README 中的 pdfkit 示例）把条/模块直接输出为 pdfkit `rect/path/fill` 调用——全矢量、无栅格化（M20）。
- 模块宽度：按模板 `dpi` 把 X 维取整到整数点，再换算为 pt（1pt = 1/72in）。
- **PDF 页面尺寸 = 标签尺寸，一页一张**（热敏模板）；A4 模板一页多联；横向标签（70×30 等）在 PDF 中固定页面方向（M31）。
- **ZPL：实验性（M5 可选）**：只含 ASCII 编码与条码，开头 `^CI28`，中文名称省略或 `^GF` 栅格化；不做 9100 直发/Browser Print（M32）。
- 模板为 TS 数据（`packages/labels`），纯函数 `renderPdf / renderZpl`，可单测。

## 2. 内置模板（含容量）
| key | 尺寸 | 用途 | 内容 | 默认 X 维 | maxModules |
|---|---|---|---|---|---|
| `loc-100x50` | 100×50mm | 仓位 | 大号编码（≥ 10mm）+ Code128 + 小 QR + 仓库代码 + 层箭头 | 0.375mm（203dpi 3 点）/ 0.338mm（300dpi 4 点） | 260 |
| `loc-60x40` | 60×40mm | 仓位（层板架） | 编码 + Code128 | 0.25mm（2 点，近距） | 230 |
| `loc-70x30` | 70×30mm | 横梁窄标 | 编码 + Code128 | 0.25mm | 270 |
| `rack-100x150` | 100×150mm | 货架端头/高位 | 货架码超大字 + 大 QR（≥ 50mm） | — | — |
| `a4-3x8` | A4 3×8（70×37mm） | 仓位/SKU | 编码 + Code128 | 0.25mm | 270 |
| `a4-2x7` | A4 2×7（99×38mm） | 仓位 | 编码 + Code128 + QR | 0.33mm | 290 |
| `sku-60x40` | 60×40mm | SKU | 名称两行 + 条码（合法 EAN-13 用 EAN，否则 Code128） | 0.25mm | 230 |
- 条高：仓位标签 ≥ 15mm（M30）；静区 ≥ 10X。
- **容量校验**：渲染前计算 Code128 模块数（含静区），超过 `maxModules` → 报错并建议更宽模板；设计器保存编码模式时校验"最长载荷 ≤ 默认模板容量"（02 §3.1）。默认载荷 `WH1.A03-17-C02`（14 字符）Code128 约 189 模块 + 静区 20 = 209 模块：`loc-100x50` @0.375mm ≈ 78mm，`loc-60x40` @0.25mm ≈ 52mm，均可放下（maxModules = 可用宽度 / X 维，向下取整）。
- A4 模板支持起始格与偏移校准（用户偏好）。

## 3. 条码内容
- 仓位/货架：载荷 `{WarehouseCode}.{code}`（仓库开关关闭时为裸编码，见 02 §3.2）；QR 内容与 Code128 相同（不放 URL）。
- 人眼文字：大号显示 `code`（不含前缀），小号显示仓库代码与名称。
- 字体：内嵌 Noto Sans SC 子集。

## 4. 打印流程（PC）
选对象 → 选模板 → 预览（首页实时）→ 下载 PDF → 用系统 PDF 阅读器/浏览器打印。
- 页面上显著提示：**缩放选"实际大小 / 100%"，关闭"适合纸张"，纸张选与模板一致的自定义尺寸**（M31）。
- **校准页** `/labels/calibration.pdf?template=`：10mm 刻度尺 + 测试条码 + 边框，首次使用先打一张核对。
- 用户手册附 TSC / 佳博（Gprinter）/ 斑马驱动"自定义纸张 100×50"的设置步骤。
- 批量上限 5,000 张/次（流式生成）；审计记录。
- **补打请求**（M33）：移动端（OPERATOR）在仓位详情点"标签损坏，申请补打" → `label-reprint-requests` → PC 标签页"待补打"队列一键打印。布局发布返回的"待补打清单"也进入该队列。

## 5. 张贴规范与核对
同高同侧张贴；层标签贴横梁正中下方；高位用 `rack-100x150` 或大 QR。张贴后用平板 **标签核对模式**（04 §3.6，M4.5 交付）逐个扫描，3D 点亮，漏贴一目了然。

## 6. 测试
